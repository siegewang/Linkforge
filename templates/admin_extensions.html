Browser Extension Installation & Verification Guide

Chrome / Brave / Edge:
  1. Download and unzip dashforge-chrome.zip.
  2. Navigate to chrome://extensions in your browser.
  3. Enable Developer Mode (toggle in top-right corner).
  4. Click Load unpacked and select the extracted folder.
Firefox Installation & Verification:
  • Method 1 — Instant Testing (Any Firefox):
    Go to about:debugging#/runtime/this-firefox, click Load Temporary Add-on..., and select the downloaded dashforge-firefox.xpi (or manifest.json).
  • Method 2 — Permanent Local Install (Firefox Dev Edition / Nightly / ESR):
    Go to about:config, set xpinstall.signatures.required to false, then drag & drop the .xpi file into Firefox.
  • Method 3 — Official Mozilla Signing (Standard Firefox Release):
    Mozilla requires signing for permanent installation in regular Firefox. Upload to AMO Developer Hub (choose "On your own / Self-distribution") or run npx web-ext sign --api-key=... --api-secret=... for an instantly signed .xpi.
